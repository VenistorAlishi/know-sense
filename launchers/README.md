# Ярлыки запуска Смысл

| Файл | Для кого |
|---|---|
| `Запуск Смысл.bat` | Windows — двойной клик из клона репо |
| `smysl-jarvis.desktop` / `Смысл Jarvis.desktop` | Linux |
| `../scripts/launch-jarvis.sh` | Linux/macOS CLI |
| `npm run shortcut` | поставить `.desktop` в меню и на `~/Desktop` |

На Windows скопируйте `Запуск Смысл.bat` на рабочий стол (или сделайте ярлык на него).
